# Inventory Management System

A CLI-based Inventory Management System developed using Python, applying core programming concepts and problem-solving techniques.

## Key Features

- Manage inventory and product records
- Add, update, and remove stock
- Search and retrieve product information
- Generate inventory reports

## Python Concepts Used

- **Object-Oriented Programming (OOP):** Classes, objects, encapsulation, and inheritance
- **Data Structures and Algorithms (DSA):** Lists, tuples, dictionaries, searching, and sorting
- **Functions:** Modular and reusable code
- **Control Flow:** Conditional statements and loops
- **Exception Handling:** Handling errors and invalid inputs
- **Input Validation:** Ensuring correct user input
- **File Handling:** If implemented in the project

## Technologies

- Python
- Command-Line Interface (CLI)

## How to Run

1. Install Python.
2. Clone or download the repository.
3. Open a terminal in the project directory.
4. Run the main Python file:

```bash
python main.py
```
